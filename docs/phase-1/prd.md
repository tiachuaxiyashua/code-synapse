# 一期产品需求文档（PRD）

## 1. 背景

AI 写代码的速度超过初学者逐行阅读和建立心智模型的速度。现有代码图偏向符号和调用关系，密集网络不解释“功能有什么用”；一次性 AI 讲解又会压缩、遗漏并丢失层级。Code Synapse 需要验证一种持久、可导航、可核查的解释模型是否能解决这个问题。

## 2. 目标用户

一期只面向不懂编程或代码能力较弱、正在使用 AI coding 的用户。用户能描述产品需求，但不了解框架惯例、调用、参数、事件、分支、模块边界等概念。

不以资深程序员的代码检索效率作为一期优化目标。

## 3. 样例与场景

样例使用固定提交的真实 TypeScript Web 项目，必须包含：请求入口、嵌套调用、依赖注入、至少一个条件分支、返回结果和事件派发。一期固定分析注册与登录范围，避免用整个仓库规模掩盖语义模型问题。

核心场景：

- 用户想知道“注册功能从收到请求到完成做了什么”；
- 用户想知道“登录成功和失败分别由什么条件决定”；
- 用户想知道“某一步给下一步传了什么”；
- 用户想确认图上的解释是否真由源码支持；
- 用户放大查看函数细节后仍能回到完整流程，不丢失归属。

## 4. 产品需求

### P1-1 功能树

系统必须在独立网页中用树展示能力、用例和子功能。每个项目显示名称、面向初学者的作用摘要和是否有下层。选择项目必须打开或聚焦流程页，并定位其语义区域。

验收：用户不需要知道函数名就能找到注册或登录；选择后流程页出现对应选中态。

### P1-2 顶层完整流程

Z0 必须展示选定范围的完整主路径、主要选择和最终结果。Z0 只允许聚合细节，不允许为了简洁而删除影响用户理解的失败结果或异步事件。

验收：用户只看 Z0 能说出流程从哪里开始、主要做什么、成功和失败去哪里。

### P1-3 全局语义缩放

鼠标滚轮必须改变整张流程图的语义层级，而不是只缩放像素。Z0 为能力/用例，Z1 为领域步骤和分支，Z2 为函数或实现步骤组。同一层级在同一时刻全局生效；中键拖动只改变视口。

验收：连续滚轮可按顺序进入三个层级；缩小可返回；层级切换后父流程边界与选中对象的归属可辨认；中键拖动不改变层级。

### P1-4 条件、结果与完整选择

所有展示的条件分支必须同时保留已发现的替代路径，边或选择节点显示人能读懂的条件及结果。没有当前配置或输入值时显示“尚未绑定”，不能显示概率或“可能调用”来代替源码声明的条件。

验收：登录成功与失败都存在，用户能从图上读出各自条件和结果。

### P1-5 数据与事件传递

关系必须说明传递方向、内容和用途。至少展示一次函数参数/返回值和一次事件消息。标识符原样保留，旁边增加所选解释语言的含义。

验收：用户能回答“哪一步把什么交给了谁”和“注册后发出了什么事件”。

### P1-6 就近解释与固定

指向节点或边时，说明框必须在对象和指针附近跟随移动，并进行视口碰撞处理。说明包含作用、为什么存在、输入、输出、主要副作用和证据数。单击后说明固定；点击外部或 Escape 取消；固定说明提供“查看实现”。

验收：说明不出屏、不遮住当前对象；固定后移动鼠标不会消失；查看实现按钮可用。

### P1-7 源码证据

“查看实现”在当前流程页旁打开编辑器式抽屉，显示仓库相对路径、原始行号、源码片段、对应主张和证据类别。关闭抽屉不能重置视口、层级或选择。

验收：所有功能性主张至少有一条有效证据；文件与行号和固定提交匹配。

### P1-8 状态与失败透明

系统必须区分源码声明、当前选择、分析缺口和仓库外边界。模型或页面遇到缺失证据、悬空关系、未知层级时必须明确失败，不能静默省略。

验收：校验器拒绝无证据主张、悬空边和缺失关键路径；页面能显示分析缺口而不是空白。

## 5. 非功能需求

- 主要目标是桌面浏览器；一期最小支持 1280x720 和 1440x900。
- Z0 每张图不超过 30 个节点、50 条关系；一期实际目标低于 15/25。
- 初始页面只读取当前层级数据；不得把所有层级同时渲染后用 CSS 隐藏。
- 源码和模型均视为不可信输入；页面只以文本渲染，不执行样例代码或注入 HTML。
- 所有长期文件使用仓库相对路径；生成产物可重建，不提交 CodeGraph 数据库。
- 解释语言在样例导入时固定为中文，源码标识符不翻译。

## 6. 指标与决策

| 指标 | GO 门槛 |
| --- | --- |
| 无证据的功能性主张 | 0 |
| 关键主路径遗漏 | 0 |
| 错误条件、结果或传递 | 0 |
| 程序员手工拓扑重建 | 0 |
| 核心理解题正确率 | 100% |
| 相比点击下钻更难的核心任务 | 0 |
| 相比点击下钻更容易的核心任务 | 至少 3 项 |

## 7. 发布判定

一期不是公开产品版本。通过时只授权下一条窄生产切片：验证第二种流程语法和模拟区域加载；不自动授权多语言、所有图种或生产架构。
