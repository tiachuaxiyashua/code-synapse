# 一期工程实施说明

## 1. 一期要回答的问题

Code Synapse 一期不是产品底座建设，而是一次可丢弃、可证伪的纵向可行性验证。它只回答一个问题：

> 能否把真实 TypeScript 项目的 CodeGraph 结构事实和源码，转换成有证据的功能树与分层流程，使不懂编程的用户从“系统做什么”逐步理解到“代码怎样实现”，并且始终知道每条解释来自哪里？

如果这个问题没有被真实用户验证，SQLite 适配、多语言、增量分析、更多图种、插件和性能工程都没有建设价值。

## 2. 一期交付物

一期结束时必须存在一条可运行链路：

```text
固定版本的真实 TypeScript 样例
  -> CodeGraph SQLite 与源码证据
  -> 有界的语义模型 JSON
  -> 功能树 + 独立流程页面
  -> 全局语义缩放 Z0/Z1/Z2
  -> 分支条件、结果与数据传递
  -> 相邻源码证据抽屉
  -> 自动真实性检查 + 初学者理解测试
```

交付物包括：

- 可复现的样例获取与 CodeGraph 建图命令；
- 一份可人工审阅、可由程序校验的语义模型；
- 一份功能树和一个流程图页面，二者是独立网页；
- 鼠标滚轮控制全局语义层级，中键拖动画布；
- 节点与关系的悬浮说明、点击固定和源码证据抽屉；
- 自动化真实性与交互测试；
- 面向目标用户的手动理解测试报告；
- `GO / REVISE / STOP` 决策，不以“页面完成”代替产品验证。

## 3. 文档与真相边界

产品长期设计的唯一入口仍是 `docs/design/README.md`。本目录只说明一期如何验证其中的核心假设，不能改变长期产品定义。

一期文档按以下顺序阅读：

1. `docs/phase-1/feature-breakdown.md`：功能层级和一期取舍；
2. `docs/phase-1/prd.md`：用户、场景、需求与验收；
3. `docs/phase-1/software-design.md`：最小软件架构、数据契约和错误边界；
4. `docs/phase-1/extensibility-review.md`：为什么这个最小框架不会阻塞后续扩展；

## 4. 一期边界

### 必须做

- 只分析一个固定提交的真实 TypeScript 项目；
- 直接使用 CodeGraph 已生成的 SQLite 结构事实和精确源码；
- 允许当前 AI 编程代理执行一次受约束的语义建图，输出必须落盘；
- 只实现功能树与流程图两种视图；
- 流程图至少覆盖三个语义层级、一个成功分支、一个失败分支、一次参数或返回值传递、一次事件传递；
- 每个对用户展示的功能性主张必须连接精确代码行或 CodeGraph 事实；
- 用真实目标用户完成理解测试。

### 明确不做

- Python、JavaScript 独立样例以及 C、C++、C#、GDScript；
- 生产级 CodeGraph SQLite 版本适配与增量索引；
- 自动 AI API、模型选择、密钥配置和 Provider 抽象；
- 分层架构、交互、时序、数据流、状态机、运行时间线、通信时序等其他图；
- Diff 叠加、冲突判断、配置绑定和运行时证据；
- Codex/Claude Code Skill、注释生成 Skill 和自动维护；
- 大仓库流式加载、区域缓存、多人协作、账号、云服务和发布安装包；
- 对现有 `prototype/` 做兼容性改造。旧原型只是视觉证据，新验证页使用独立入口。

## 5. 成功标准

一期只有满足以下全部条件才是 `GO`：

1. **真实性**：展示内容无编造，主流程无遗漏，条件、结果和数据传递无错误；所有主张可回到证据。
2. **逐级理解**：用户能从 Z0 总览，经 Z1 领域步骤到 Z2 实现步骤，且能说明细节属于哪个上层流程。
3. **操作成立**：滚轮改变全局语义层级，中键只平移；功能树定位、悬浮、固定说明和源码抽屉均可实际使用。
4. **理解成立**：目标用户不先读源码，也能正确回答 `docs/phase-1/manual-test-plan.md` 的关键问题。
5. **生成成本可接受**：不需要程序员手工重画拓扑；人工只允许纠正语义标签，且全部纠正有记录。

事实正确但交互或层级令人困惑时为 `REVISE`，只修改失败的模型或交互后重测。出现编造、主路径缺失，或必须由程序员手工重建流程时为 `STOP`，先推翻语义建图方法，不进入底座开发。

## 6. Ponytail Gate

`Ponytail Gate: passed (full)`。

门禁删除了所有不能直接验证核心假设的基础设施。复用现有 React/Vite 试验环境、浏览器原生 SVG 与事件、Node 标准库校验、现有 CodeGraph 产物和当前 AI 代理；一期不新增图引擎、后端服务、数据库、AI SDK 或测试框架。
